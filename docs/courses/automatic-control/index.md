## 复习路线

1. **状态空间与响应**：理解模型，会求解状态方程，注意保留非零初始状态项。
2. **能控能观与系统设计**：掌握秩判据，再练习状态反馈、极点配置与观测器。
3. **稳定性与解耦**：整理 Lyapunov 判据、可镇定性与解耦条件。
