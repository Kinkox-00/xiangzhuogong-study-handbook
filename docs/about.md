# 关于手册

湘卓工学习手册是一份由学习者整理、向同学开放的课程复习资料。我们希望把分散在课件、教材与课堂笔记里的线索，整理成可以连贯阅读、方便复习的知识路径。

## 这里有什么

- **量化工程分析**：图论、最优化控制、拉格朗日力学和轮式机器人运动学。
- **计算机系统**：数据表示、汇编、存储、链接、进程与优化。
- **自动控制原理**：目前聚焦现代控制理论，覆盖状态空间、反馈与稳定性。
- **数理综合（一）**：课程内容待补充。
- **数理综合（二）**：课程内容待补充。

已收录的课程资料包括概念说明、求解方法与补充例题。课程概览会说明内容范围；尚未填充的课程标为“待补充”。

## 如何对待这些笔记

本手册是学习辅助资料，不是学校或学院发布的官方教材，也不代表课程的最终考试范围。资料中的结论、符号和假设应与课堂要求和原始教材核对。

对于需要进一步确认的推导，欢迎提供出处与修改建议。每一项有依据的改进，都能让下一位读者少走弯路。
